# Privacy notice — PromQL and Prometheus Rules plugin

The PromQL and Prometheus Rules plugin runs entirely inside your IDE. It does **not** collect, store or transmit any
personal data, usage statistics, telemetry or file contents, and it makes no network connections. Links in the
quick-documentation popup open the public Prometheus documentation (prometheus.io) in your browser only when you click them.

If you contact us through GitHub issues, GitHub's privacy policy applies to what you post there; we only use it to
answer your request.
